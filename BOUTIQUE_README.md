# Boutique en ligne Coton FC

Bienvenue dans la boutique en ligne officielle du Coton FC ! Cette section vous permet d'acheter des produits dérivés du club, notamment des écharpes, des casquettes, des gourdes et bien plus encore.

## Fonctionnalités

- **Navigation par catégories** : Filtrez les produits par catégorie (écharpes, casquettes, gourdes, etc.)
- **Filtrage des produits** : Trouvez facilement les produits qui vous intéressent
- **Sélection de couleurs et tailles** : Personnalisez certains produits selon vos préférences
- **Ajout au panier** : Ajoutez des produits à votre panier en un clic
- **Notifications** : Recevez des confirmations visuelles lors de l'ajout au panier
- **Design responsive** : Profitez d'une expérience optimale sur tous les appareils

## Structure des fichiers

- `boutique.html` - Page principale de la boutique
- `assets/css/derives.css` - Styles pour la section des produits dérivés
- `assets/js/derives.js` - Fonctionnalités interactives de la boutique
- `assets/images/boutique/` - Dossier contenant les images des produits
- `download_derived_images.js` - Script pour télécharger les images des produits (à personnaliser avec vos propres URLs)

## Personnalisation

Pour ajouter de nouveaux produits, modifiez la section HTML dans `boutique.html` en suivant la structure existante. Assurez-vous d'ajouter les images correspondantes dans le dossier `assets/images/boutique/`.

## Notes techniques

- La boutique utilise Bootstrap 5 pour la mise en page
- Les animations sont gérées par CSS et JavaScript natif
- Le panier utilise le stockage local du navigateur pour conserver les articles
